# Acar Web

## Configuracion local

1. Instala Node.js 18 o superior.
2. Ejecuta `npm install`.
3. Copia `.env.example` a `.env` y completa los datos SMTP de la cuenta que enviara los mensajes.
4. Ejecuta `npm start` y abre `http://localhost:3000`.

Los formularios envian los mensajes a `contacto@acaraseo.cl` y agregan `rahumada@acaraseo.cl` en copia. El formulario de postulacion acepta archivos PDF, DOC y DOCX de hasta 5 MB.
